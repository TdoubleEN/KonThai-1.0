# KonThai

สกิลช่วยเกลาภาษาไทย ไทยปนอังกฤษ และอังกฤษให้อ่านลื่น เป็นธรรมชาติ ลดคำฟุ่มเฟือยและภาษา AI โดยรักษาความหมาย น้ำเสียง และข้อมูลเดิม เหมาะกับแคปชั่น บรีฟ บทความ อีเมล และงานเขียนทั่วไป

## ทำอะไรได้บ้าง

- ลดคำเกริ่น ความซ้ำ และประโยคที่เหมือนแปลตรงตัว โดยไม่บังคับให้ทุกงานมีน้ำเสียงเดียวกัน
- รักษาตัวเลข หน่วย ชื่อสินค้า เงื่อนไข คำว่า “อาจ” ข้อความอ้างอิง ลิงก์ และแฮชแท็ก
- เคารพขอบเขตงาน: ตรวจภาษาอย่างเดียวจะคงโครงเดิม ส่วนการเรียบเรียงใหม่ปรับโครงได้
- ข้อความที่ดีอยู่แล้วคงไว้ ไม่แก้ทุกประโยคเพียงเพื่อให้ดูว่าได้ทำงาน
- มีตัวช่วยเปรียบเทียบข้อมูลก่อน/หลังสำหรับงานที่รายละเอียดเยอะ ใช้เมื่อต้องการ

สกิลเป็นชุดคำแนะนำให้ AI ไม่ใช่โมเดลภาษาและไม่ใช่โปรแกรมเขียนบทความอัตโนมัติ ต้องใช้ผ่านเครื่องมือที่รองรับ SKILL.md เช่น Codex หรือ Claude Code การเกลาข้อความปกติไม่ต้องติดตั้ง Python เพิ่ม

## ติดตั้ง

### Codex

บอก Codex ว่า:

> ติดตั้งสกิลจาก https://github.com/TdoubleEN/KonThai-1.0 โดยใช้โฟลเดอร์รากของ repo และตั้งชื่อสกิลว่า konthai

หรือติดตั้งด้วย Git บน Windows (PowerShell):

```powershell
git clone https://github.com/TdoubleEN/KonThai-1.0.git "$env:USERPROFILE/.codex/skills/konthai"
```

บน macOS / Linux:

```sh
git clone https://github.com/TdoubleEN/KonThai-1.0.git ~/.codex/skills/konthai
```

สกิลควรปรากฏในเทิร์นถัดไป หากยังไม่พบให้เปิดแชตใหม่ เรียกด้วย `$konthai` หรือบอกว่า “ใช้ KonThai เกลาข้อความนี้”

### Claude Code

ติดตั้งไว้ในโฟลเดอร์สกิลของ Claude Code แทน:

```sh
git clone https://github.com/TdoubleEN/KonThai-1.0.git ~/.claude/skills/konthai
```

Windows PowerShell ใช้ปลายทาง `"$env:USERPROFILE/.claude/skills/konthai"` จากนั้นเรียก `/konthai` ในแชตใหม่ รูปแบบไฟล์เตรียมให้พกไปใช้ได้ แต่รุ่นนี้ทดสอบเรียกโมเดลจริงใน Codex เท่านั้น ยังไม่ได้ทดสอบ Claude Code จริง

หากโฟลเดอร์ `konthai` มีอยู่แล้ว คำสั่ง clone จะหยุด ให้ตรวจของเดิมก่อน เมื่อต้องการอัปเดตสำเนาที่ติดตั้งด้วย Git ให้รัน `git pull --ff-only` ภายในโฟลเดอร์นั้น

ไม่ใช้ Git ก็ได้: กด **Code → Download ZIP** แตกไฟล์ เปลี่ยนชื่อโฟลเดอร์เป็น `konthai` แล้ววางในตำแหน่งเดียวกัน โดยต้องมี `konthai/SKILL.md` โดยตรง ไม่ซ้อนโฟลเดอร์อีกชั้น

## ตัวช่วยตรวจข้อมูลก่อน/หลัง (ไม่จำเป็นสำหรับทุกงาน)

ต้องมี Python 3.9 ขึ้นไป ไม่ใช้ไลบรารีภายนอก จากโฟลเดอร์ที่มี SKILL.md:

```sh
python scripts/compare_protected.py --before before.md --after after.md
```

เพิ่ม `--protect terms.json` เพื่อรักษาถ้อยคำเฉพาะ โดย `terms.json` เป็น JSON เช่น `["Example Brand", "Approved CTA"]` ถ้าเรียกจากโฟลเดอร์อื่นให้ใช้พาธเต็มของสคริปต์และไฟล์ทั้งสอง

ผลลัพธ์เป็น JSON: exit code **0** ไม่พบความต่างที่ติดตาม, **1** มีจุดให้ตรวจ, **2** ข้อมูลนำเข้าหรือคำสั่งผิด สคริปต์อ่านอย่างเดียว ไม่แก้ไฟล์ ดู [รายละเอียดและข้อจำกัด](references/checker.md)

## ขอบเขตที่ควรเข้าใจ

KonThai ช่วยด้านภาษา การเกลาสำนวนไม่ได้ยืนยันความจริงของคำกล่าวอ้างสินค้า และ checker ไม่เข้าใจความหมายทุกกรณี เช่น การสลับเจ้าของตัวเลขที่ใช้หน่วยเดียวกันอาจตรวจไม่พบ ต้องเทียบต้นฉบับประกอบ

ไม่มีระบบรับประกันผ่าน AI detector และไม่รับประกันเปอร์เซ็นต์ประหยัดโทเคน ผลขึ้นกับข้อความ โมเดล และเครื่องมือที่ใช้ สกิลและสคริปต์ไม่มีการเรียกบริการภายนอกเอง แต่ข้อความยังถูกประมวลผลตามบริการโมเดลที่คุณเลือก
