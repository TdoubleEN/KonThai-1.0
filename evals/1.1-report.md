# KonThai 1.1.0 — ผลทดลอง 20 ตุลาคม 2026

เพิ่มแนวทางเสริมเรื่องโครงสร้างประโยคไทย เจ้าของข้อมูล/เงื่อนไข มุมผู้พูด–ผู้อ่าน และระดับภาษา โดยปรับจากแนวคิดที่เลือกใช้ใน kien-thai พร้อมเครดิตและ MIT license ไม่เพิ่มการตรวจวนหรือการเรียกโมเดลอื่น

## สิ่งที่นำขึ้นใช้จริง

คำสั่งหลักเหมือนรุ่น 1.0 ทุกตัวอักษร ยกเว้นเลขเวอร์ชัน ความรู้ใหม่อยู่ใน references/thai-patterns.md ซึ่งเปิดเมื่อมีปัญหาภาษาไทยที่ต้องวิเคราะห์เพิ่มเท่านั้น เนื้อหาแนวทางเสริม 2,011 ตัวอักษร เทียบกับเดิม 2,246 ตัวอักษร จำนวนตัวอักษรไม่ใช่จำนวนโทเคน

ทดลองต้นแบบที่เพิ่มกฎในคำสั่งหลักก่อนสองแบบ ผู้ประเมินชอบของเดิมมากกว่าในรายละเอียดสำนวน จึงไม่เผยแพร่ต้นแบบเหล่านั้น ฉบับสุดท้ายคงขั้นตอนเดิมและใช้แนวทางใหม่เป็นตัวเลือกตามบริบท

## วิธีเทียบ

ใช้โจทย์สังเคราะห์เดียวกัน 10 ข้อ โมเดล gpt-6.1-sol, reasoning high และรูปแบบผลลัพธ์เดียวกัน ป้อน SKILL.md พร้อมแนวทางภาษาไทยทั้งไฟล์ ไม่มี tool call ระหว่างสร้างคำตอบ ใช้ค่า CLI ที่รายงานจริง

| รุ่น | Input | Output | รวม input + output |
|---|---:|---:|---:|
| 1.0 | 22,459 | 1,307 | 23,766 |
| 1.1 | 22,396 | 1,129 | 23,525 |

รวมลด 1.01% เฉพาะรอบนี้ Input รวมบริบทระบบ/เครื่องมือร่วมของ CLI; Output รวม reasoning ตามที่ระบบรายงาน ไม่บวก reasoning ซ้ำ และไม่อ้างว่าทุกงานจะประหยัดเท่ากัน

## คุณภาพ

ให้ผู้ประเมินโมเดลอ่านต้นฉบับกับคู่คำตอบที่สลับป้าย A/B โดยไม่เห็นรุ่นหรือชุดคำสั่ง: เลือก 1.1 ใน 2 กรณี (ความชัดของเงื่อนไขที่ผูกกับผลิตภัณฑ์ และการแก้เฉพาะจุดในงาน proofreading), เสมอ 8 กรณี, เลือก 1.0 จำนวน 0 กรณี ไม่พบความผิดสาระสำคัญในชุดสุดท้าย

ตัวตรวจข้อมูลไม่พบการเปลี่ยนตัวเลข หน่วย URL แฮชแท็กที่ติดตามทั้งสองรุ่น ทั้งนี้ตัวตรวจไม่เข้าใจความหมายทั้งหมด การตัดสินด้านความหมายมาจากการอ่านเทียบต้นฉบับ

นี่เป็น pilot ที่ใช้โจทย์เดิมระหว่างปรับและมีผู้ประเมินโมเดลเพียงตัวเดียว ไม่ใช่การทดสอบชุดใหม่ที่ไม่เคยเห็นหรือหลักฐานเชิงสถิติ ยังต้องดูจากงานจริงและเสียงของเจ้าของงาน ไม่รับประกันว่าจะเขียนดีกว่าทุกกรณีหรือประหยัดโทเคนทุกงาน
